## STR Quality Standards

1. All projects follow **responsive, mobile-first** design
2. Code must pass **W3C validation**
3. SEO basics (meta tags, sitemap, robots.txt) included by default
4. Tested across Chrome, Firefox, Safari, Edge (latest 2 versions)
5. Mobile tested on Android (Chrome) and iOS (Safari)
6. Performance: target Lighthouse score ≥ 80 on all deliverables
7. Source code handed over to client upon project completion
8. Post-delivery support: 30 days bug fix warranty standard
